    Terms of Use

    The short version: this site teaches web security. The lab it describes is a training target, built to be broken. Run it locally, keep the skills legal, and take everything here as-is.

    Educational purpose

    Everything on this site exists to teach web application security: how vulnerabilities work, how to find them, and how to fix them. By using this site, you agree to use it for that purpose.

    The lab is intentionally vulnerable

    • It is a target, not a service. PenTrix VulnLab is built to be exploited on purpose. That makes it a training target, not something you should ever rely on.
    • Run it locally only. Run the lab on your own machine or an isolated lab network. Never expose it to the internet or to shared networks: a public deployment of intentionally vulnerable software will be compromised.
    • This site is not the lab. These pages are static documentation. The actual lab software comes from the PenTrix VulnLab repo and has its own license; that license governs the software, these terms govern this website.

    Use the skills responsibly

    Do not use anything you learn here against systems you do not own or do not have explicit permission to test. Unauthorized testing is illegal in most places and can have serious consequences. If you want real targets, use your own lab, a bug bounty program that authorizes you, or a provider that offers testing environments.

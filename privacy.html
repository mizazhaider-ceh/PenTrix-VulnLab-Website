    Privacy Policy

    The short version: this website is a collection of static pages. It collects no personal data, sets no cookies, and runs no analytics or tracking.

    What we do not collect

    • No accounts. There is no sign-up, no login, and no profile on this site.
    • No forms. Nothing here asks for your name, email, or any other personal information.
    • No cookies. This site does not set, read, or use any cookies or local storage trackers.
    • No analytics. There is currently no analytics, no visitor counting, and no behavioral tracking of any kind.

    Third-party requests

    Loading this site makes a small number of third-party requests. These are the only ones:

    • Google Fonts. The site loads font files from Google Fonts so the text looks the way it was designed. Those requests go to Google's servers. See Google's privacy policy for how Google handles that traffic.
    • GitHub Pages hosting. The site is hosted on GitHub Pages, which serves the page files. GitHub may keep standard web server logs (such as IP addresses and requested pages) as part of operating the hosting service. See the GitHub privacy statement for details.

    If we ever add analytics or any other third-party service, this page will be updated first.

    The lab software and your data

    PenTrix VulnLab itself runs entirely on your own machine when you install it. Your progress, flags, and certificates stay on that machine and are never sent to this website or to us. This website has no way to see what you do inside the lab.

    Contact

    Questions about this policy? Open an issue on the PenTrix VulnLab GitHub repo and we will answer there.

    Changes to this policy

    If this policy changes, the updated version will be posted here with a new effective date. The change takes effect as soon as it is posted.

    PenTrix VulnLab is intentionally vulnerable. Run it only on your own machine.

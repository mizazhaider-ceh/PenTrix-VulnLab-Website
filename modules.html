    29 Modules, 201 Challenges

    The lab is a small town of vulnerable web apps, and each module is one neighborhood. Every module focuses on one bug family, every challenge is a real page you poke at with real tools, and every flag is earned by real exploitation: nothing here is given away by reading the source.

    Foundations

    Start here: the core web flaw families every tester meets first, in small, forgiving challenges.

    CSRF & Clickjacking

    Forge cross-site requests against tokenless state-changing endpoints, sneak JSON requests past naive checks, and frame pages missing frame protection.

    5 challengesBeginner

    CSV Formula Injection

    Poison a contact export so spreadsheet apps run your cells: classic formulas, DDE commands, hyperlinks, and pipe-prefixed LibreOffice payloads.

    4 challengesBeginner

    HTTP Layer Flaws

    Work directly with raw HTTP behavior: forge log lines through header injection, swap request verbs, and trick a cache key into serving the wrong user.

    3 challengesBeginner

    Broken Access Control

    Act as a regular user who reaches other people's data by changing ids, visiting hidden admin pages, and touching functions the app never guarded.

    7 challengesBeginner

    Security Misconfiguration

    Survey a carelessly deployed app: read debug errors, exposed backups, .env and .git, directory listings, default credentials, and open upload endpoints.

    10 challengesBeginner

    Open Redirect

    Trace unvalidated redirect parameters across five labs, probing allowlist tricks, odd schemes, and duplicate parameters that steer users to attacker pages.

    5 challengesBeginner

    Cross-Site Scripting

    Hunt nine cross-site scripting flaws across reflected, stored, and DOM flavors, learning where browsers will happily run your injected script.

    9 challengesBeginner

    Auth and Sessions

    Identity is the prize: logins, tokens, and session state, and every way they can break.

    Broken Authentication

    Attack broken logins: brute-force an endless login page, predict reset tokens, guess short OTPs, trick security questions, and spot enumerable usernames.
